From a business profile to content decisions

One browser origin, a persistent API, and workers that finish the expensive work.

Frontend
Typed services make HTTP calls. Signals render state. Polling ends on a terminal run or route destruction.
Backend
Flask validates and queues a run. The worker orchestrates pure agents and commits progress to PostgreSQL.
Provider boundary
The recording uses FakeLLMClient. OpenAI and Anthropic use the same validated agent contract.
Discovery
Generate questions and upsert them by profile and normalized question text.
Scoring
Work in batches of five. Derive visibility and the opportunity score in code.
Recommendations
Use the highest-scoring absent-domain queries. Validate references before replacing content ideas.
Visibility, volume and difficulty are estimates. This demo uses a separate database and no live-provider key.
